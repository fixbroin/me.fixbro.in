WeCanFix - Multi-Vendor Handyman & on-Demand Service Booking Platform

WeCanFix is a complete, enterprise-grade on-demand handyman and home services marketplace built using Next.js (App Router), MySQL, and Firebase Authentication. It comes out-of-the-box with a high-converting customer booking website, a dedicated provider management panel, and a robust administrative control center—all optimized for high speed, search engine dominance, and minimal hosting costs.

This platform is designed to run perfectly on standard Linux VPS servers or premium shared hosting plans supporting Node.js. It features automatic job dispatching, a state-of-the-art booking engine, built-in backup systems, and localized SEO landing page auto-generators.

High-Performance Tech Stack

  • Next.js (App Router): High-performance server-side rendering (SSR) and incremental static regeneration (ISR) for lightning-fast page loading.
  • MySQL Database: Secure, industry-standard relational database support for robust transaction handling, indexing, and high data integrity.
  • Firebase Authentication: Seamless OTP/SMS login, Google single sign-on (SSO), and secure email/password credential registers.
  • REST API Architecture: Standardized Next.js Route Handlers function as backend API endpoints. This allows developers to easily extend the platform or build native mobile apps (Flutter, React Native) on top of the existing backend database.
  • Triple PWA Configurations: Fully configured Progressive Web App (PWA) manifests. The customer portal, provider panel, and admin dashboard can all be installed directly onto iOS, Android, or desktop devices as standalone apps.

Advanced Booking Scheduler & Slot Engine

  • Auto-Generated Booking Slots: The engine automatically compiles available booking slots based on provider schedules, break times, and overlapping bookings.
  • Customizable Time Intervals: Set time intervals to 30-minute, 60-minute, or custom durations globally from the Admin Panel.
  • Buffer & Booking Duration Rules: Define service buffer times and default execution duration per service to prevent scheduling conflicts.
  • Timezone & Calendar Controls: Automatic local timezone handling, customizable business holidays, provider leaves, and vacation schedulers.
  • Same-Day Bookings: Enable or disable same-day reservation cutoffs dynamically.

Automated Job Dispatch & Provider Panel

  • Smart Radius-Based Dispatch: The system automatically calculates coordinates and alerts the nearest active service providers within a customizable geographic radius.
  • Provider Service Zones: Providers can manage their own service zones, operating coordinates, and maximum travel radiuses via their private panels.
  • Four-Step Provider Onboarding: Streamlined provider signup with verification steps, document submissions, and profile configurations.
  • Admin Assignment Override: Administrators can manually allocate bookings, reassign providers, or override automated dispatch logic at any time.
  • Earnings & Withdrawals Dashboard: Detailed transaction ledgers, referral earnings tracking, and withdrawal requests manager for providers.

Advanced SEO Page Auto-Generator (OpenStreetMap Integration)

  • Mass SEO Page Generation: Instantly generate search engine optimized landing pages for specific cities, regions, and service categories without writing manual content.
  • OpenStreetMap-Based Location Lookup: Utilizes geocoding data to automatically create highly localized SEO landing pages mapped to exact coordinate parameters.
  • Structured Breadcrumbs & Schema Metadata: Built-in JSON-LD schemas and semantic layouts for local service businesses to boost Google Search rankings.
  • Google Indexing API Integration: The system compiles new URLs and submits indexing requests automatically to the Google Search Console via an automated daily cron job.

Dual Storage Drivers (VPS vs. Shared Hosting)

  • Local Storage Mode: Saves files and images directly to your VPS SSD drive in the public uploads directory.
  • Remote Shared Hosting PHP Bridge: Route media assets to a cost-efficient shared hosting subdomain (e.g., Hostinger) using a secure PHP bridge script. This keeps your VPS backup files small, saves disk bandwidth, and prevents storage billing spikes.

Robust Admin Tools & Business Management

  • One-Click Backups and Restoration: Export your database schema into a JSON file snapshot and package all media uploads into a ZIP archive directly from the admin panel. Restore the system with a single click.
  • Dynamic Gateway Keys & Marketing IDs: Configure Razorpay API credentials, Google Analytics 4 Measurement IDs, Microsoft Clarity Project IDs, Pinterest Tags, Bing Ads UET tags, and Firebase VAPID keys directly through the Admin UI.
  • Multi-Currency Auto-Configuration: Change your operational country in settings; the system dynamically adjusts currency symbols, formatting rules, and correct decimal processing units.
  • Quotation & Invoice System: Create custom service quotes for clients, send them directly, and instantly convert accepted quotes into paid invoices.
  • Review Management: Moderate customer reviews, publish test responses, or load pre-configured demo reviews.
  • Flexible Fee Configurations: Manage platform service fees, minimum booking fees, and custom visiting charges per booking.

Hosting & Software Requirements

  • Application Server: Linux VPS (Ubuntu 20.04/22.04 LTS recommended) or a Premium Shared Hosting account with Node.js support enabled.
  • Runtime: Node.js v18 or v20 LTS.
  • Database: MySQL Server v8.0 or higher.
  • Map Services: Valid Google Cloud Project with Maps Javascript API and Geocoding API keys enabled.
